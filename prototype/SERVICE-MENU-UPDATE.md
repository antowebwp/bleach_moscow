# Обновление по пожеланиям заказчика — 20 октября 2026

## Текущее уточнение

По последующей корректировке заказчика полноэкранный блок из четырёх сцен и бегущая строка восстановлены на главной. Компактные плитки размещаются только вместо прежнего блока услуг, после блока о мастерской.

Каталог снова использует прежнюю композицию «фотография + раскрывающиеся услуги», теперь с четырьмя направлениями: «Обувь», «Сумки», «Сервис Loro Piana», «Химчистка». Обувная чистка и реставрация объединены без повторяющихся пунктов. Разделы ателье и брендов в перечне направлений убраны. Отдельный блок логотипов остаётся ниже каталога.

Блок брендов расширен до 10: Loro Piana, Chanel, Gucci, Dior, Yeezy, Santoni, Prada, Louis Vuitton, Brunello Cucinelli, UGG. Дополнительные логотипы берутся из существующих изображений портфолио через SVG-кадрирование без изменения исходных фотографий. Все ссылки фильтруют примеры работ по выбранному бренду.

Актуальная сборка: `node build-service-menu.cjs` (вызывает `restore-catalog.cjs`), затем `node build-shared.cjs`. Восстановленная разметка хранится в `home-about.html`, `home-offer.html`, `catalog-layout-template.html`. Текст ниже описывает предыдущую итерацию, заменённую этим уточнением.

Главная: новый первый экран с формулировками «Премиальный сервис», «Химчистка и реставрация», «Обувь · Одежда · Сумки». После него идут три направления: обувь (5 услуг), сумки (5), одежда (3). Крупные фотографии до/после и прежний полноэкранный блок убраны с главной; портфолио остаётся на странице брендов. Плитки используют существующие фотографии чистых изделий и работы мастера; для одежды добавлены SVG-иконки пальто, сорочки и трикотажа. Отзывы, процесс передачи вещей и общие контакты сохранены.

Каталог: три текстовых списка из 20 пунктов заказчика. Готовые страницы FULL, Loro Piana, химчистки одежды и портфолио доступны по ссылкам. Для остальных пунктов открывается общая консультация с названием выбранной услуги. Дополнительные страницы услуг не имитируются. Оригинальные описания работ остаются в раскрываемом разделе «Подробнее о возможностях мастерской».

Montserrat Regular (400) добавлен локально для навигации на всех страницах. Палитра и общие отступы сохранены.

Данные новых направлений экспортируются в `service-menu-data.json`. Сборка главной и каталога: `node build-service-menu.cjs`, затем `node build-shared.cjs`. Будущий ACF: повторитель направлений (id, заголовок, краткий текст), внутри повторитель услуг (название, ссылка на запись, изображение). WordPress пока не подключается.

Анимации: появление заголовков и небольших плиток, последовательное появление строк каталога, существующий прогресс этапов сервиса. `prefers-reduced-motion` отключает движение. Мобильное меню сохраняет выезд справа налево.
