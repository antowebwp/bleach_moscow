# BLEACH MOSCOW: прототип главной

Локальный прототип на HTML/CSS/JS. Исходная WordPress-тема не изменена.

Запуск из этой папки:

```powershell
node server.cjs
```

Открыть http://127.0.0.1:4173/ . Остановить сервер: Ctrl+C.

Файлы: index.html, styles.css, main.js. Дизайн-токены, состояния компонентов, доступность и схема переноса в WordPress: DESIGN.md.

Сохранен порядок восьми секций home.php с общим блоком контактов footer.php. Фото скопированы из исходного проекта. GSAP и ScrollTrigger загружаются локально; GSAP отключается при reduced motion. Без JavaScript контент остается доступным, но интерактивные кнопки требуют JavaScript.

Ограничение: база WordPress/ACF не предоставлена. Каталог, галерея и процесс содержат демонстрационное наполнение; реальные цены, полные отзывы и дополнительные адреса нужно подключить при переносе. Окна консультации предлагают реальные телефон и MAX из исходников. Они не отправляют заявки; Contact Form 7 остается в исходной теме.

Референс: https://solefresh.ru/ . Брендинг и изображения SOLE FRESH не скопированы.

Inter: @fontsource-variable/inter 5.2.8, SIL Open Font License. GSAP/ScrollTrigger: 3.13.0, условия GreenSock указаны в заголовках файлов vendor.
