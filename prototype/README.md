# BLEACH MOSCOW: прототип главной

Локальный прототип на HTML/CSS/JS. Исходная WordPress-тема не изменена.

Запуск из этой папки:

```powershell
node server.cjs
```

Открыть http://127.0.0.1:4173/ . Остановить сервер: Ctrl+C.

Файлы: index.html, styles.css, main.js. Дизайн-токены, состояния компонентов, доступность и схема переноса в WordPress: DESIGN.md.

Сохранен порядок восьми секций home.php с общим блоком контактов footer.php. Фото скопированы из исходного проекта. GSAP и ScrollTrigger загружаются локально; GSAP отключается при reduced motion. Без JavaScript контент остается доступным, но интерактивные кнопки требуют JavaScript.

Ограничение: база WordPress/ACF не предоставлена. Каталог, галерея и процесс содержат демонстрационное наполнение; реальные цены, полные отзывы и дополнительные адреса нужно подключить при переносе. Окна консультации предлагают реальные телефон и MAX из исходников. Они не отправляют заявки; Contact Form 7 остается в исходной теме.

Референс: https://solefresh.ru/ . Брендинг и изображения SOLE FRESH не скопированы.

Inter: @fontsource-variable/inter 5.2.8, SIL Open Font License. GSAP/ScrollTrigger: 3.13.0, условия GreenSock указаны в заголовках файлов vendor.

Services prototype: http://127.0.0.1:4173/uslugi.html (or /prototype/uslugi.html under Live Server). Shared interactions live in ui.js; home animations in main.js; catalog interactions in services.js. Original ACF WordPress template remains unchanged.

## Страница одной услуги
`chistka_obuvi_full.html` — отдельный прототип FULL. Состав, цена 5 000 ₽ и шесть фото взяты из актуального HTML https://bleach.moscow/chistka_obuvi_full/ (12.10.2026). Montserrat 600/700 применяется в навигации всех страниц и внутри `.full-main`; это приближение к референсу OSKELLY, точная гарнитура макета не подтверждена. Лицензия: assets/Montserrat-OFL.txt.

Контакты и футер: единый источник `shared-footer.html`. После правок выполнить `node prototype/build-shared.cjs` из корня проекта. Фрагмент встраивается в три HTML и доступен без JavaScript; позже переносится в WordPress footer.php. Новые логотипы — исходные PNG пользователя, SVG лишь задаёт кадрирование без пустых полей.

Общие раскрытия и мобильное меню: ui.js, плавные прерываемые переходы, reduced motion, управление клавиатурой. Изображения не выделяются и не перетаскиваются. План интеграции ACF и проверки SEO: WP-MIGRATION.md.

## Бренды и примеры работ
`brand.html` — каталог 82 уникальных кейсов / 38 брендов из действующего сайта. 83 исходные карточки содержали повтор одной страницы Dior; он объединён. `cases/*.html` — самостоятельные страницы кейсов, создаются единым `build-brands.cjs` из `brands-data.json`. В каталоге есть живой поиск, фильтры по бренду/типу изделия и пустое состояние. Плотная галерея в 4/3/2 колонки сохраняет пропорции изображений без добавленной подложки. Карточка целиком ведёт на страницу кейса; заголовок, вид работы и сумма видны при hover/focus, на touch — постоянно. Быстрый просмотр удалён. GSAP: бегущая строка с паузой, появление первого экрана, сборка первых 12 карточек при прокрутке, смена результатов и последовательное появление этапов кейса. ResizeObserver адаптирует masonry к натуральной высоте изображений и подписей. Reduced motion отключает движение.

Фотографии, оригинальные описания, состав и суммы перенесены со страниц кейсов. Сумма на подробной странице приоритетнее старой цены карточки. Индивидуальные причины выбора метода не придумывались: общий блок о подборе ухода отделён от списка выполненных работ. Галереи исходных страниц пустые; данные и шаблон поддерживают будущую ACF-галерею.

Обновить данные: `node prototype/import-brands.cjs`. Собрать страницы: `node prototype/build-brands.cjs`. Синхронизировать общий футер: `node prototype/build-shared.cjs`. Импорт использует сохранённый HTML brand-source.html и загружает только реальные изображения bleach.moscow. Служебные исходники, данные импорта и генераторы не являются файлами для публикации на WordPress.

- Это обычные статические HTML-страницы; WordPress и ACF не используются. Общий генератор `node build-uniq.cjs`, стили `uniq.css`, анимации `uniq.js`. Сохранённые `*-source.html` нужны только сборке, их не публиковать как страницы.
